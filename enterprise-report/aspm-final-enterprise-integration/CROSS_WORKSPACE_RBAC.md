# RBAC обоих пространств

| Principal | Classic | DevSecOps |
| --- | --- | --- |
| SECOPS | Разрешённое управление Products, Product Types, Engagements и Tests, включая создание Product Type | Обе структуры, управление политиками и явно предоставленными настройками интеграций |
| EXPERT | Глобальный доступ к AppSec-данным, создание и правки Engagement/Test по правилам, ручной Finding, триаж и разрешённый API import/reimport | Просмотр доказательств и генерация отчётов по действующим разрешениям |
| USER | Гранты Product через Keycloak. Просмотр разрешённых Product, Engagement, Test, Finding и отчётов | Те же гранты ограничивают репозитории, коммиты, артефакты и отчёты |
| Сервисный аккаунт | Штатная аутентификация и объектные разрешения Classic API | Для ASPM v1 действуют выделенные операции и Product/Repository scope токена |

USER видит Product Type только через предоставленные Products. Списки и счётчики Product Type отфильтрованы, а отчёт на весь Product Type закрыт, поскольку он может включать чужие Products. Backend проверяет исходный Product у Engagement, Test, Finding и отчёта. Reader может сформировать отчёт в пределах разрешения на чтение.

EXPERT не получает системное администрирование. USER не получает права изменения через Classic API. При этих проверках использовались серверные ответы для прямых URL, включая запросы после Keycloak login. Реальная связка корпоративных AD-групп требует отдельной проверки на целевом staging.
