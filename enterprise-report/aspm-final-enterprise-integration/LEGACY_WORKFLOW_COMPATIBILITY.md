# Совместимость классического процесса

| Сценарий команды | Вход в процесс |
| --- | --- |
| DAST и инфраструктурные сканирования | Existing Product и Engagement либо Test, штатный API с поддерживаемым форматом сканера |
| Pentest и периодическая оценка | Ручное создание Engagement и Test при наличии разрешения, ввод Findings и нативный отчёт |
| Действующие CI/CD и сервисные интеграции | Штатный токен или другая поддерживаемая аутентификация, существующее разрешение import/reimport на объект |
| Git CI/CD | Scoped ASPM token, Repository и Commit, автоматический выбор Engagement и публикация Zero-Finalize |

Product Type, Product, Engagement, Test и Finding сохраняют штатные страницы и операции с учётом серверных разрешений. В Classic доступны настройки и метрики Product, тип, сроки и статус Engagement, контекст сканера и история импорта Test, а также триаж, заметки и отчёты. Существующие действия управления жизненным циклом и семантика дедупликации сохраняются.

При включённой `DD_ASPM_API_ONLY=True` загрузка файлов сканеров через UI запрещена для всех ролей. Ручной ввод Finding и создание Test через разрешённые механизмы остаются доступны. Classic API сохраняет штатную проверку плагина-сканера и объектного разрешения на импорт.
