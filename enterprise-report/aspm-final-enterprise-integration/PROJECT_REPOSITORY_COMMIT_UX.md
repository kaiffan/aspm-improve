# Project, Repository and Commit workflow

The Projects page links to the existing repository views. Commit evidence shows coverage and completed, pending and failed scanners. Scanner Reports shows original filenames, artifact digests, timestamps, status and selected environment. Historical findings paginate by cursor. Report artifacts remain behind a Product-scoped download check.

The Changes page computes absences only against comparable coverage. It shows an explicit warning when scopes or pipeline contexts differ, when a scanner failed or when coverage is unknown. A Project with no completed scan displays an empty or unknown state.

Existing polling and SHA-copy behavior are reused. The new pages add scoped project search and accessible form labels. A representative browser capture is retained under raw.
