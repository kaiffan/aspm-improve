# Role workspaces

Keycloak login opens Projects. A User starts at My projects and enters the established Repository, Commit, Scanner Reports and ASPM Report pages. Access-scoped search filters the portfolio on the server. Internal Product tabs, mutation actions and credential controls are omitted for this role.

Experts have all-Project and live Finding entry points and can use the existing triage surface. SecOps has additional navigation for scanner integrations, outbound webhooks, SSO mappings, diagnostics and settings. Project and Repository pages link to Engagement policy where the backend grants management.

The same permissions apply to direct requests. Hiding controls in a template does not grant an action.
