# ASPM Premium UI и Kubernetes HA

Кандидат ASPM 1.0.1 развёрнут в OrbStack с Chart 0.1.0-rc.7 и Helm revision 10. Доступен локальный HTTP и проверенный TLS Ingress. Две web replicas содержат совместные nginx/Django, три worker обслуживают общую очередь, один Beat координирует outbox.

Интерфейс сохраняет Classic и DevSecOps и использует общую адаптивную оболочку. Projects показывает последнюю доставку, Repository фильтрует ветки, Commit сохраняет статусы, историю, сравнение и экспорты. Проверки охватывают синтетические роли SecOps, Expert и User с портфелями из одного, двух и нуля проектов.

Замена web pod прошла с 1 057 HTTP 200, сохранением сессии и совпадающими SHA-256. Прерванный ScanRun завершился после автоматической повторной доставки. Сценарий с 2/3 при сопоставимом бюджете показал 126.71 RPS против 84.50 у 1/1 на малом датасете.

Полный Django suite прошёл 8 356 тестов с 553 унаследованными пропусками. Chromium завершил 208 загрузок и 27 действий, Helm прошёл 19 тестов и живой smoke после масштабирования.
