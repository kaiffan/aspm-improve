# Доступность

Запущен axe-core с тегами WCAG 2.0, 2.1 и 2.2 AA в Chromium. Выполнены поиск с клавиатуры, открытие фильтров Findings пробелом и закрытие мобильной навигации Escape с возвратом фокуса.

| Страница | axe-core |
|---|---|
| projects | Нарушения не отмечены |
| processing | Нарушения не отмечены |
| reports | Нарушения не отмечены |
| findings | target-size (serious, 17 целей) |
| health | Нарушения не отмечены |

Проверки экранным диктором, полного focus trap и динамических объявлений об ошибках остаются NOT TESTED. Результаты ограничены просмотренными состояниями и элементами.
