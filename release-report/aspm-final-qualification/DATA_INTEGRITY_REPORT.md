# Целостность данных

HTTP проверил отдельные Test у завершённых scanner runs одного commit, повторный запрос с прежним ключом и идентичные SHA-256 оригиналов. После позднего scan контрольные суммы HTML и JSON предыдущего отчёта совпали: True. Синтетический некорректный scanner file завершился FAILED без Findings: 0.

Для отдельного восстановления сверены 8 строк ScanRun и SHA-256 каждого восстановленного оригинала. Квалификация всех PostgreSQL ограничений, истории отчёта после S3 disaster restore, реальных Keycloak mappings и ожидающих outbox jobs остаётся открыта.
