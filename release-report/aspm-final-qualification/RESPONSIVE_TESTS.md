# Responsive и темы

Проверка фиксировала разницу между шириной документа и viewport после применения каждой темы. Порог — не более одного пикселя общего overflow. Внутренняя прокрутка таблиц разрешена.

| Viewport, px | Light | Dark | System |
|---|---:|---:|---:|
| 320 | 8 | 8 | 8 |
| 360 | 3 | 3 | 3 |
| 390 | 8 | 8 | 8 |
| 768 | 3 | 3 | 3 |
| 1024 | 3 | 3 | 3 |
| 1280 | 3 | 3 | 3 |
| 1440 | 8 | 8 | 8 |
| 1920 | 3 | 3 | 3 |

На части размеров повторены Projects, Reports и Scan Processing. Для 320, 390 и 1440 добавлены Classic, Findings, Dashboard, System Health и Repositories. Значения представляют фактические измерения, включая браузерные переходы. Длинные пользовательские тексты и крупные отчёты на всех ширинах остаются NOT TESTED.
