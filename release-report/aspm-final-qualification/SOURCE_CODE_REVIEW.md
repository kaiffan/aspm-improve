# Ревью исходного кода

Просмотрены границы транзакций при приёме ScanRun и записи outbox, блокировки Repository при назначении Engagement, хранение SHA-256 и публикация двух частей отчёта, граница приватного каталога, authorization на чтение, health probes, сборка образов и скрипт передачи в registry. Неизменяемость отчётов проверена через реальный API. Валидация конфигурации storage оставила запрет на публичный каталог, при этом ошибка преобразуется в отказ с HTTP 503 и диагностируемый статус зависимости.

Ruff 0.16.10 прошёл для runtime-правок, их регрессионных тестов и теста publish-images. Полный прогон обнаружил 21 600 замечаний. В поддеревьях dojo, unittests и deploy/handover отдельный прогон нашёл 485 замечаний. Это открытый CI-риск. Аудит всех upstream handlers, dependency CVE и каждого скрипта резервного копирования на этой ревизии не завершён.
