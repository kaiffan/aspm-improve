# Безопасный откат

Изменений схемы/индексов в RC нет. Откат — переключение app/nginx и background workers на сохранённую согласованную пару образов Round 5 с той же схемой 3.5.100 и теми же media. Данные не удаляются и не восстанавливаются поверх живой БД ради отката UI.

1. Остановить приём новых импортов, дать текущим задачам завершиться. Зафиксировать состояние очереди. Не запускать old/new Celery одновременно над одной БД.
2. Сохранить private env, image IDs и backup. Остановить RC app/nginx/worker/beat без удаления volumes.
3. Запустить предыдущие проверенные app/nginx/worker на прежних настройках. Проверить health, restricted API, finding count и импорт. Сбросить только принадлежащий приложению namespace полноcтраничного cache или дождаться TTL, чтобы не показывать смешанный UI. Не использовать FLUSHALL общих cache/broker.
4. localStorage `aspm.theme` безопасно игнорируется предыдущей версией. При необходимости удалить только этот ключ в браузере.

Для локального стенда достаточно остановить проект aspm-rc1; 8080 продолжает использовать прежнюю сборку. Отдельная БД aspm_rc1_validation намеренно сохраняется со smoke fixtures. Исходная БД, seed и media не удаляются. Предыдущие benchmark-sidecars восстанавливаются отдельно; это не production deployment.

Для изменения кода использовать `git revert` тематических UI/branding-коммитов в отдельной ветке с повторной проверкой; не применять reset/clean к пользовательской рабочей директории. Git history Round 1–5 сохранена.
